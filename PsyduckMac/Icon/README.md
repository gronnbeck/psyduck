# App icon

An amber (`#E6A300`) rounded square with the np.lol ink border and hard
shadow, and ψ (psi, for psyduck) in Georgia Bold. There is no source artwork:
`make-icon.swift` *is* the artwork (tsukue's generator with the glyph and
colour changed).

```sh
cd PsyduckMac/Icon
swift make-icon.swift ../Sources/Assets.xcassets/AppIcon.appiconset
```
